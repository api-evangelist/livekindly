## Notes for agents

- Reads need no credential. Writes need a WordPress Application Password (HTTP Basic); the MCP
  endpoints need an OAuth bearer token with scope `mcp`.
- There is **no idempotency key**, **no rate-limit header**, **no request id** and **no ETag** on
  this API. Retries are unsafe on writes and unobservable on reads.
- Errors use the WordPress envelope `{code, message, data.status}` — not RFC 9457 problem+json.
  A 403 may come from the Sucuri WAF as **HTML**, not JSON: branch on content-type.
- `brand`, `partner` and `job` return title, slug and link only. The substance lives in the HTML
  page at `link`, not in the JSON.
- No status page, no SLA, no changelog, no deprecation policy. Treat the surface as
  unversioned-in-practice: 15 of the 21 namespaces belong to third-party plugins that can change
  without notice.
